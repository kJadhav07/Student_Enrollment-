Student Enrollment System

A beginner-friendly, menu-driven Student Enrollment System built with Python. It helps a college or institute manage student records, course enrollment, and fee details. Student information is saved in a JSON file.

Features:
- Add, view, search, update, and delete student records
- Enroll students in Python, Data Science, Web Development, and SQL
- View total, paid, and remaining fees
- Validate student details and fee amounts
- Save and load records using JSON

Technologies: Python 3, JSON, OOP, functions, dictionaries, loops, conditions, exception handling, and file handling.

Run the project:
python student_enrollment.py
